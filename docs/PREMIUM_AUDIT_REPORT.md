## Нерешённые ограничения (честно)

1. Нет кастомных иллюстраций пустых состояний/онбординга (кат. 2, −0.5).
   Причина: нет дизайнера/ассетов в репо. Рекомендация: 3–4 SVG в ЛОР-тематике
   в `frontend/src/assets/`.
2. Нет анимации потокового ответа чата и pull-to-refresh (кат. 3, −0.5).
   Причина: backend отдаёт ответ целиком; SSE не внедрён. Рекомендация:
   `/chat/stream` + пословный рендер.
3. Админ-загрузка: `alert()` + захардкоженный `http://localhost:8000`
   (кат. 7, −0.5). Причина: вне скоупа прохода, не сломано — но требует
   доработки на `VITE_API_URL` + тосты. Зафиксировано в KNOWN_ISSUES.md.
4. Нет экспорта логов для техподдержки (кат. 7). Нет прогона на физическом
   устройстве/скринридере (кат. 6–7) — нет доступа в этой сессии.
5. Flutter-пункты брифа (adaptive icon, splash, go_router, haptics, APK-размер,
   WorkManager, TalkBack-натив) — N/A: mobile-фаза заблокирована до установки
   Flutter 3.x + Android SDK (см. KNOWN_ISSUES.md).
