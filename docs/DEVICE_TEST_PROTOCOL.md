# DEVICE TEST PROTOCOL — 15 минут на реальном Android (перед первым врачом)

Готовит: владелец пилота. Нужны: Android-телефон с Chrome, URL развёрнутого
фронтенда (https или http://<IP>:5173 в той же Wi-Fi сети), запущенный backend.

## A. Установка (3 мин)
1. Открыть URL в Chrome → дождаться загрузки чата.
2. Меню ⋮ → «Установить приложение» (или дождаться баннера «Установите ЛОРАИ»).
3. Проверить: иконка ЛОРАИ на главном экране; запуск — standalone, БЕЗ адресной строки.
4. ⬜ Пройдено / ⬜ Нет пункта «Установить» → записать модель Chrome в отчёт.

## B. Приёмный сценарий (7 мин, как на приёме — одной рукой, быстро)
5. Чат: «Острый средний отит: диагностика и лечение?» → ответ идёт ПОТОКОМ
   (текст дописывается, не ждём конца). Засечь время до первого слова: ___ с.
6. Источники раскрываются, дозировка в ответе совпадает с протоколом.
7. Поиск: «H66» → открыть чек-лист → отметить 2 пункта → Печать/PDF (превью).
8. Калькуляторы: Centor 2 балла; PTA [20,20,25,15] → 20 дБ.
9. Дифдиагностика: «оталгия, лихорадка» → ранжирование + red-flags при тризме.
10. Тёмная тема: переключить → всё читаемо, контраст ок.
11. ⬜ Всё открывается за ≤2 тапа с главного экрана чата.

## C. Офлайн (3 мин)
12. Открыть любой протокол (чтобы закэшировался) → включить АВИАРЕЖИМ.
13. Обновить открытый протокол → открывается из кэша (баннер «Нет соединения» в шапке).
14. Новый вопрос в чате в офлайне → понятная ошибка + кнопка повтора.
15. Выключить авиарежим → повтор проходит.

## D. Ввод и доступность (2 мин)
16. Голосовой ввод (микрофон клавиатуры Gboard) в поле чата → текст вставляется.
17. Увеличить шрифт системы до максимума → вёрстка не ломается, кнопки ≥ пальца.
18. Кнопка «Сообщить о проблеме» → тестовый report виден в БД (таблица feedback).

## Фиксация результата
- Модель телефона / версия Chrome / время первого токена / скрины проблем.
- Не прошёл пункт — завести report через саму кнопку в приложении.
- Минимум: 2 разные модели телефонов до выдачи первому врачу.
