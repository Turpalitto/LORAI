# Архив документов

Исторические брифы и отчёты прошлых проходов. **Не источник истины**: цифры и
описания в них относятся к своим версиям и с тех пор изменились. Актуальное
состояние — `README.md`, `docs/ARCHITECTURE.md`, `docs/KNOWN_ISSUES.md`,
`docs/RETRIEVAL_EVAL.md`, `CHANGELOG.md`.

| Файл | Что это | Версия |
|---|---|---|
| `AGENT_BRIEF.md` | постановка для агента на этапе 1 | 1.0 |
| `AUDIT_BRIEF.md` | бриф аудита | 1.1 |
| `EXCELLENCE_BRIEF.md` | бриф этапа «excellence» | 1.2 |
| `PREMIUM_AUDIT_BRIEF.md` | бриф премиум-аудита | 1.3 |
| `FINAL_REPORT.md` | сводный отчёт по ранним этапам | 1.0–1.3 |

Перенесены из корня, чтобы корень не выглядел как набор конкурирующих
источников правды (H19 аудита 2026-10-21).
